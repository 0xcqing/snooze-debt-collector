# snooze-debt-collector

A make.fun bounty entry that pitches one ridiculous invention in a single sentence: the Snooze Debt Collector, a machine that lets you hit snooze and then follows you to work with a tiny invoice charging you for the nine minutes you borrowed, plus interest. The repository is a zero-dependency TypeScript program (`main.ts`) that writes the final pitch to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`) as UTF-8 text, one sentence plus a trailing newline, and asserts the file stays within the bounty's 1-to-200-character gate before exiting.
